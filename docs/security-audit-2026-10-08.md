# 开源发布安全检查报告

检查日期：2026-10-08  
检查版本：0.3.0

## 结论

代码可在完成本报告所列修复后公开发布。当前 Git 工作树和全部提交历史中未发现 `.env`、用户数据库、私钥或常见格式的真实 API Token。项目目录中的本地 `.env` 已在发布前删除，运行数据库、虚拟环境和构建目录均由 `.gitignore` 与发布校验器排除。

## 已完成检查

- 检查当前 Git 跟踪文件以及全部提交历史中的敏感路径和常见密钥特征。
- 使用 Bandit 扫描 `app/`、`scripts/`、`config.py` 与 `run.py`。
- 使用 pip-audit 按 `requirements.txt` 查询已知依赖漏洞。
- 运行发布校验器，拒绝环境文件、数据库、虚拟环境、日志、私钥、常见 Token 与外部 CDN。
- 运行 Python 编译检查、全部前端 JavaScript 语法检查与 84 项自动化测试。

## 已修复问题

1. 删除含本地外部服务凭据的 `.env`；保留无密钥的 `.env.example`。
2. 将 Flask、Werkzeug、python-dotenv、requests、pytest 与 pypdf 升级到已修复版本，pip-audit 复扫为 0 个已知漏洞。
3. 注册密码长度限制调整为 8～128 位，登录入口拒绝超长密码，降低弱密码与昂贵哈希输入风险。
4. 永久会话有效期缩短为 12 小时；生产模式继续要求固定 `FLASK_SECRET_KEY` 并启用 Secure Cookie。
5. 扩展发布校验器对 GitHub、AWS、Google、OpenAI 风格 Token 与私钥的识别。
6. 增加安全报告策略、MIT 许可证、GitHub Actions 安全测试和 Dependabot 更新配置。

## 现有防护

- 密码使用 Werkzeug 安全哈希，不保存明文。
- 登录失败按来源和账号限流；跨来源写请求被拒绝。
- 会话 Cookie 使用 HttpOnly 与 SameSite；生产模式使用 Secure。
- 响应包含 CSP、禁止嵌入、禁止 MIME 嗅探、Referrer Policy 与 Permissions Policy。
- 上传总量和语音大小、时长受限；知识文档仅由管理员导入并在内存中解析。
- API 异常不返回堆栈、请求体、Cookie、回答或凭据。
- 用户只能读取和删除自己的业务数据，管理员接口具有角色校验。

## 仍需注意的边界

- Flask 自带开发服务器只适合本机演示；公网部署需使用生产 WSGI、HTTPS、反向代理和持久化限流。
- 当前登录限流存储在单进程内存中，多实例部署需改为 Redis 等共享存储。
- 本次检查不是完整渗透测试，也未覆盖云平台、操作系统和反向代理配置。
- 删除本地文件不能撤销已通过截图、聊天或其他渠道暴露的密钥；所有曾使用的 API Key 应在服务商控制台轮换。
- 开源前应确认题库、图片和竞赛相关素材具有公开分发权限；MIT 许可证不替代第三方素材授权。
